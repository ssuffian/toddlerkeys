Ubuntu and Debian

Install on Linux

Add the Toddler Keys package source once. New versions will then arrive with your normal system updates.

Copy these commands into Terminal:

curl -fsSL https://ssuffian.github.io/toddlerkeys/toddlerkeys-archive-keyring.gpg | sudo tee /usr/share/keyrings/toddlerkeys-archive-keyring.gpg >/dev/null
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/toddlerkeys-archive-keyring.gpg] https://ssuffian.github.io/toddlerkeys stable main" | sudo tee /etc/apt/sources.list.d/toddlerkeys.list
sudo apt update
sudo apt install toddlerkeys
